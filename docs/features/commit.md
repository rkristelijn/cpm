# cpm commit

Interactive conventional commit helper.

## Usage

```bash
cpm commit
```

## What it does

Guides you through creating a conventional commit message:

```
<type>(<scope>): <description>
```

Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `ci`

## Why

Consistent commit messages enable automated changelogs, semantic versioning, and clear git history.
