# ISO/IEC 25010:2023 — Software Product Quality

ISO 25010 defines 9 quality characteristics for software products. cpm uses it as its quality taxonomy — every check maps to at least one characteristic. This document maps cpm's ~790 rules to the 2023 revision of the standard.

## Coverage Summary

| Characteristic | Sub-characteristics | cpm Coverage | Primary Rules |
|---|---|---|---|
| Functional Suitability | Completeness, Correctness, Appropriateness | ●●○○○ ~25 | TEST-\*, QUAL-050/060/068/070 |
| Performance Efficiency | Time Behavior, Resource Utilization, Capacity | ●●●○○ ~30 | K8S limits, SLS-\*, GQL limits, CSS-PERF-\*, timeout rules |
| Compatibility | Co-existence, Interoperability | ●●●○○ ~45 | API-\*, GQL-\*, GRPC-\*, TRANS-\*, 12F-\* |
| Interaction Capability | Inclusivity, Operability, Learnability, + 5 more | ●●●●● ~150 | A11Y-001–120, STYLE-020/021/022, CSS-A11Y-\* |
| Reliability | Faultlessness, Fault Tolerance, Availability, Recoverability | ●●●○○ ~35 | QUAL error handling, RES-\*, K8S probes, 12F shutdown, MIG-\* |
| Security | Confidentiality, Integrity, Authenticity, + 3 more | ●●●●● ~280 | SECRETS-\*, SEC-\*, SCA-\*, BE-\*, WEB-\*, OAUTH-\*, SESS-\* |
| Maintainability | Modularity, Reusability, Analysability, Modifiability | ●●●●○ ~90 | QUAL-047, STYLE-026, MIG-015, 12F-\*, BNDL-\* |
| Flexibility | Testability, Adaptability, Scalability, Installability, Replaceability | ●●●○○ ~55 | TEST-019, 12F-\*, K8S-\*, BNDL-\*, API-\*, SH-\* |
| Safety | Operational Constraint, Risk Identification, Fail Safe, + 2 more | ●●●○○ ~80 | SCA-068, 12F-\*, RES-\*, CICD-SEC-\* |

## Detailed Mapping

### 1. Functional Suitability

Degree to which the product provides functions that meet stated and implied needs.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Completeness | TEST-001–015 (coverage gates), QUAL-068 (feature coverage) | ~15 |
| Correctness | TEST-016–018 (assertion quality), QUAL-050 (mutation testing) | ~5 |
| Appropriateness | QUAL-060 (test-to-code ratio), QUAL-070 (dead code) | ~5 |

- **Gap**: No requirements-to-test traceability yet (planned: `cpm trace`)
- **Gap**: No formal specification validation

### 2. Performance Efficiency

Performance relative to the amount of resources used.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Time Behavior | SLS-001–005 (Lambda timeouts), GQL-010 (query depth), CSS-PERF-001–008 | ~15 |
| Resource Utilization | K8S-020–025 (resource limits/requests), BNDL-001–005 (bundle size) | ~10 |
| Capacity | GQL-011 (pagination limits), K8S-026 (HPA config), SLS-006 (concurrency) | ~5 |

- **Gap**: No runtime benchmarking (planned: `cpm bench`)
- **Gap**: No memory profiling rules

### 3. Compatibility

Degree to which a product can exchange information with other products.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Co-existence | 12F-001–012 (twelve-factor), K8S-001–010 (port/env config) | ~20 |
| Interoperability | API-001–015 (OpenAPI/versioning), GQL-001–009, GRPC-001–005, TRANS-001–006 | ~25 |

- **Gap**: No protocol conformance testing (e.g., HTTP/2, WebSocket)

### 4. Interaction Capability

Degree to which the product can be interacted with by specified users.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Inclusivity | A11Y-090–120 (WCAG AA), STYLE-020 (inclusive language) | ~35 |
| Operability | A11Y-030–060 (keyboard nav, focus management) | ~30 |
| Learnability | A11Y-001–029 (labels, alt text, ARIA) | ~30 |
| User Error Protection | A11Y-061–075 (form validation, error messages) | ~15 |
| Appropriateness Recognizability | STYLE-021 (consistent naming), CSS-A11Y-001–010 | ~15 |
| User Engagement | STYLE-022 (responsive design), CSS-A11Y-011–015 | ~10 |
| User Assistance | A11Y-076–089 (help text, tooltips, status messages) | ~10 |
| Self-descriptiveness | STYLE-020 (semantic HTML), A11Y-001 (page titles) | ~5 |

- **Gap**: No mobile-specific interaction checks (EN 301 549)

### 5. Reliability

Degree to which a system performs specified functions under specified conditions.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Faultlessness | QUAL-030–040 (error handling, null checks), RES-001–005 | ~15 |
| Fault Tolerance | K8S-030–035 (probes, restart policy), 12F-011 (graceful shutdown) | ~8 |
| Availability | K8S-036–038 (replica count, PDB), RES-006–008 (circuit breaker) | ~7 |
| Recoverability | MIG-001–010 (migration safety), 12F-012 (disposability) | ~5 |

- **Gap**: No chaos engineering integration
- **Gap**: No SLA/SLO verification

### 6. Security

Degree to which a product protects information and data.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Confidentiality | SECRETS-001–080, SEC-001–020 (encryption, TLS) | ~100 |
| Integrity | SCA-001–068 (supply chain), WEB-001–013 (CSP, SRI) | ~70 |
| Authenticity | OAUTH-001–015, SESS-001–010, BE-001–017 (auth patterns) | ~40 |
| Accountability | CICD-SEC-001–015 (pipeline audit), SEC-021–034 (logging) | ~30 |
| Non-repudiation | SEC-030–034 (commit signing, audit trail) | ~10 |
| Resistance | AIML-001–025 (prompt injection), WEB-010–013 (CSRF, SSRF) | ~30 |

- **Gap**: No formal penetration testing orchestration

### 7. Maintainability

Degree of effectiveness and efficiency with which a product can be modified.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Analysability | QUAL-047 (complexity), STYLE-026 (comment ratio), QUAL-070 (dead code) | ~30 |
| Modifiability | MIG-015 (migration patterns), 12F-001–012 (config externalization) | ~25 |
| Modularity | BNDL-001–010 (bundle/package structure), QUAL-048 (fan-out) | ~20 |
| Reusability | STYLE-026 (DRY detection), BNDL-011–015 (shared modules) | ~15 |

- **Gap**: No architecture enforcement (import boundary validation planned)

### 8. Flexibility

Degree to which a product can be adapted to changes.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Testability | TEST-019 (test isolation), TEST-020 (mock boundaries) | ~15 |
| Adaptability | 12F-001–012 (env-based config), K8S-040–045 (ConfigMaps) | ~15 |
| Installability | SH-001–010 (script portability), BNDL-016–020 (package targets) | ~10 |
| Scalability | K8S-026 (HPA), SLS-006 (concurrency), API-015 (pagination) | ~8 |
| Replaceability | API-010 (versioning), GRPC-005 (backward compat), BNDL-020 | ~7 |

- **Gap**: No portability matrix (cross-OS/cross-runtime verification)

### 9. Safety

Degree to which a product mitigates potential risk to people, property, or environment.

| Sub-characteristic | Rule IDs | Count |
|---|---|---|
| Risk Identification | SCA-001–068 (CVE detection, dependency audit) | ~30 |
| Operational Constraint | 12F-001–012 (env separation), CICD-SEC-001–010 (pipeline gates) | ~20 |
| Fail Safe | RES-001–008 (circuit breakers, fallbacks), K8S-030 (probes) | ~12 |
| Hazard Warning | CICD-SEC-011–015 (deployment warnings), RES-009 (deprecation) | ~10 |
| Safe Integration | SCA-040–050 (lockfile integrity), CICD-SEC-010 (unpinned Actions) | ~8 |

- **Gap**: No formal FMEA (Failure Mode and Effects Analysis)
- **Gap**: No safety-critical certification mapping (IEC 61508, DO-178C)
